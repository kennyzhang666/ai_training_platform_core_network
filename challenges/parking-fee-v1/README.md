# 停车场计费（parking-fee-01@1）

## 交付目标

实现 `src/parking.py` 中的 `calculate_fee(entry_time, exit_time, is_member=False)`，返回两位小数的停车费用。

## 规则与约束

- 停车不超过 30 分钟免费；超过后按小时向上取整，每小时 8 元；
- 单次普通费用封顶 80 元；会员在封顶前享受 8 折；
- 支持跨天 ISO 时间；非法时间输入应由调用方收到明确异常；
- 只使用 Python 标准库，不修改隐藏测试、提交契约或平台目录；
- 交付必须包含需求说明、澄清记录和可复现的自测证据。

## 提交方式

可上传 zip，也可在场次允许时提交指定 Git 仓库的指定分支和 commit。平台会在服务端固化不可变 `snapshotHash`，不要自行把压缩包字节或 commit SHA 当作快照哈希。
