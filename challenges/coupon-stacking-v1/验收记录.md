## 上线前验收

本地没有执行公司内网 Code Agent、LDAP 或真实 PostgreSQL 训战。这道题不需要平台数据库迁移。上传引擎后，先用参考提交 ZIP 发起一人评测，确认总分 100、16 项 A，再向正式名单开放。平台自动发起与管理员发起都可使用同一引擎，首场建议集中发起并统一揭晓。

目标解释器最低为 Python 3.11，实际 Windows 验证版本为 3.12/3.13；Ubuntu 目标机与发布包内 3.11 的现场执行仍需上述参考提交验收。
