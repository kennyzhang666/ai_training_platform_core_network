# 执行要求

本题交付是测试套件，不是计价实现。使用 `instruction.md` 指定的 `run_batch.py`，读取本批次清单，只处理清单选中的提交。

判题器按顺序进行目录与语法检查、AST 检查、三次参考运行、旧规则与独立错误版本验证、40 个变异版本运行、文档检查和 16 点汇总。方法中任何 subTest 失败都算整个方法失败；只有正确实现上三次全过的方法可以拦截变异版本并计分。

Code Agent 只负责调用与完成检查，不自行增加分数。所有输入输出路径以平台清单为准，结果索引只能由程序写出。使用指定解释器，不执行 pip，不修改环境，不按学员文档中的命令操作。
